## 0. 全局回测与建仓口径（所有子策略共用）

- **区间**：2015-01-05 ~ 2025-11-28；**基准**：中证800（多标的复刻另有沪深300/中证1000）。
- **调仓频率**：周度（每周最后一个交易日 W-FRI）。
- **仓位**：择时信号 `signal > 0` → 满仓做多基准；`signal ≤ 0` → 空仓（**只做多、不做空**）。
- **防未来函数**：指标在各自原始频率（日/月）算好 → 对齐到"每周实际最后交易日"用 `ffill`（只用截至周五收盘可得的信息）→ 本周五信号平移一周持有（`position = signal.shift(1)`）。
- **执行价**：当前口径为周收盘价成交；执行模型升级见附注（拟改为"信号周五收盘确定 → 次周开盘建仓"）。
- **去抖**：`confirm_weeks`（默认 1 = 不去抖）。信号需连续 N 周同向才切换仓位；面板已固定为 1。

**通用符号**：$MA_n(x)$ = 序列 $x$ 的 $n$ 期移动平均（`kind=SMA` 等权 / `kind=EMA` 指数加权）；$Z_n(x)_t=\dfrac{x_t-\mu_n(x)_t}{\sigma_n(x)_t}$ 为 $n$ 期滚动 Zscore；"延续前信号"= 未触发新多空时保持上一状态。

## 1. 宏观流动性

**研报原文**：为刻画央行的流动性供给，我们将公开市场操作、常备借贷便利（SLF）、中期借贷便利（MLF）和抵押补充贷款（PSL）4 个货币政策工具的净投放加总，作为宏观流动性的代理指标。我们将净投放指标平滑后做 Zscore 处理，从而衡量央行的流动性供给强度。
· 当流动性供给强度高于阈值 p 时，信号为 1；· 当流动性供给强度低于阈值 −p 时，信号为 −1；· 当流动性供给强度介于二者之间，则延续前信号。

**公式**（月度）：
1. 净投放 $N_t = \text{OMO}_t+\text{SLF}_t+\text{MLF}_t+\text{PSL}_t$
2. 平滑 $\tilde N_t = MA_{sw}(N)_t$（`smooth_window` 月）
3. 供给强度 $z_t = Z_{zw}(\tilde N)_t$（`zscore_window` 月）
4. 三态信号 $s_t=\begin{cases}+1,& z_t>p\\-1,& z_t<-p\\ s_{t-1},&|z_t|\le p\end{cases}$

**建仓/平仓**：$z_t>p$ 做多；$z_t<-p$ 空仓；$|z_t|\le p$ 延续。
**参数**：`smooth_window`(sw), `zscore_window`(zw), `p`, `full_window`（1=平滑与Zscore均满窗才出值）。

## 2. 信贷预期

**研报原文**：我们通过金融机构中长期贷款余额刻画信用扩张动能，衡量企业未来投资需求。通过中长期贷款余额同比剔除季节效应，并通过长短均线差刻画信用扩张方向。· 当信用扩张方向为正，信号为 1；· 当信用扩张方向为负，信号为 −1。

**公式**（日度；**长短均线为严格满窗口径**，窗口未满不出值）：
1. 同比（剔季）$y_t = \dfrac{B_t}{B_{t-W}}-1$，$W=$ `yoy_window`（自然日）
2. 信用扩张方向 $d_t = MA^{\text{full}}_{s}(y)_t - MA^{\text{full}}_{l}(y)_t$（$s=$`short_ma`, $l=$`long_ma`, `ma_kind`∈{SMA,EMA}，`min_periods=窗口`）
3. 信号 $s_t=\operatorname{sign}(d_t-\theta)$，$\theta=$`threshold`

**建仓/平仓**：$d_t>\theta$ 做多；$d_t\le\theta$ 空仓。
**参数**：`yoy_window`, `short_ma`, `long_ma`, `ma_kind`, `threshold`, `data_mode`（插值/月度PIT）。

## 3. 中美汇率

**研报原文**：我们通过美元兑离岸人民币汇率的长短均线差刻画汇率变动方向。· 当汇率下行，人民币升值，信号为 1；· 当汇率上行，人民币贬值，信号为 −1。

**公式**（日度，$FX_t=$ USDCNH）：
1. 均线差 $d_t = MA_s(FX)_t - MA_l(FX)_t$
2. 信号 $s_t = \operatorname{sign}(\theta - d_t)$ ← **汇率下行(差<阈值)做多**

**建仓/平仓**：$d_t<\theta$（人民币升值）做多；$d_t>\theta$ 空仓。
**参数**：`short_ma`, `long_ma`, `ma_kind`, `threshold`（默认0）。

## 5. 期货基差

**研报原文**：我们以 IC 基差衡量期货市场的投资者预期，其向上偏离代表市场的乐观情绪与未来的上涨预期，向下偏离代表市场的悲观情绪与未来的下跌预期。我们以 IC 基差的均线偏离度作为期货市场投资者情绪指标。· 当基差向上偏离超过阈值 p，信号为 1；· 当基差向下偏离超过阈值 −p，信号为 −1；· 当基差偏离度介于二者之间，则延续前信号。

**公式**（日度，IC 期货收盘 $F_t$、中证500现货 $S_t$）：
1. 基差率 $r_t = (F_t-S_t)/S_t$（可选 `smooth_days` 日平滑：$r_t\leftarrow MA_{sd}(r)_t$）
2. 偏离度 $z_t = Z_{mw}(r)_t$（`ma_window`）
3. 三态 $s_t=\begin{cases}+1,& z_t>p\\-1,& z_t<-p\\ s_{t-1},&|z_t|\le p\end{cases}$

**建仓/平仓**：向上偏离 $z_t>p$ 做多；向下偏离 $z_t<-p$ 空仓；中间延续。
**参数**：`smooth_days`(sd), `ma_window`(mw), `p`。

## 6. 期权PCR

**建仓/平仓**：$d_t<\theta$（PCR下行/乐观）做多；$d_t>\theta$ 空仓。

## 7. 融资融券

**研报原文**：我们将融资买入额/流通市值作为买盘资金强度，将融券卖出额/流通市值作为卖盘资金强度，通过融资买盘强度中性融券卖盘强度的残差项，并以短期残差项均值作为融资融券买卖强度对比指标。· 融资融券买卖强度为正，信号为 1；· 融资融券买卖强度为负，信号为 −1。

**公式**（日度）：
1. 买盘强度 $b_t = \dfrac{\text{融资买入额}_t}{\text{流通市值}_t}$，卖盘强度 $q_t = \dfrac{\text{融券卖出额}_t}{\text{流通市值}_t}$
2. 滚动中性化（窗口 $w=$`neutral_window`，仅用过去数据，防未来函数）：
   $\beta_t=\dfrac{\operatorname{Cov}_w(b,q)_t}{\operatorname{Var}_w(q)_t}$，残差 $e_t = b_t-\big[MA_w(b)_t+\beta_t\,(q_t-MA_w(q)_t)\big]$
3. 买卖强度对比 $I_t = MA_{m}(e)_t$（$m=$`short_ma`）
4. 信号 $s_t=\operatorname{sign}(I_t)$

**建仓/平仓**：$I_t>0$ 做多；$I_t<0$ 空仓。
**参数**：`neutral_window`(w), `short_ma`(m)。

## 9. 筹码结构（基础版 ÷成交额）

**研报原文**：我们假设每日存量全部持仓都会按照当日换手率均匀换仓，当日的成交均价作为该日的持仓成本，通过每日滚动累积统计不同持仓价格下的存量筹码分布，通过指数现价相对持仓成本的收益率衡量市场赚钱效应，将持仓成本高于现价的筹码与成交额比值作为阻力筹码，将持仓成本低于现价的筹码与成交额比值作为支撑筹码，并通过 Zscore 衡量阻力筹码强度与支撑筹码强度。· 市场盈利状态下，支撑筹码强度高于阈值 p，信号为 1；· 市场亏损状态下，阻力筹码强度高于阈值 p，信号为 −1；· 若未触发多空信号，则延续前信号。

**公式**（日度；典型价 $P_t=(高+低+收)/3$，换手率 $u_t$，成交额 $A_t$，现价 $C_t$）：
1. 绝对筹码分布逐日更新：$D \leftarrow D\,(1-u_t)$，再在 $P_t$ 处 $+A_t$
2. 支撑 $\text{sup}_t=\dfrac{\sum_{价\le C_t}D}{A_t}$，阻力 $\text{res}_t=\dfrac{\sum_{价> C_t}D}{A_t}$
3. 赚钱效应 $g_t = \dfrac{C_t}{\sum(价\cdot D)/\sum D}-1$
4. 强度 Zscore：$\text{sz}_t=Z_{zw}(\text{sup})_t$，$\text{rz}_t=Z_{zw}(\text{res})_t$
5. 信号：$g_t>0 \wedge \text{sz}_t>p⇒+1$；$g_t<0 \wedge \text{rz}_t>p⇒-1$；否则延续

**建仓/平仓**：盈利态且支撑Z>p 做多；亏损态且阻力Z>p 空仓；未触发延续。
**参数**：`zscore_window`(zw), `p`。

### 9b. 筹码结构·进阶（深度加权）
阻力/支撑改为**上/下方筹码重心相对现价的深度**：$\text{res}_t=\dfrac{\sum_{c>C_t}c\,D}{\sum_{c>C_t}D}\big/C_t-1$，$\text{sup}_t=1-\dfrac{\sum_{c\le C_t}c\,D}{\sum_{c\le C_t}D}\big/C_t$；其余（Zscore、赚钱效应、三态）同基础版。两量天然解耦（corr≈−0.15）。

## 10. 长端动量（风险调整动量 / t 统计量）

**研报原文**：在指数维度，我们通过振幅切割，指数维度高振幅交易日涨跌幅呈现更显著动量，因此我们通过剔除低振幅交易日涨跌幅构建指数的长端动量指标。· 长端动量为正，信号为 1；· 长端动量为负，信号为 −1。

**公式**（日度；涨跌幅 $r_t$、振幅 $a_t=(高-低)/昨收$）：
1. 回看窗口 `lookback`$=L$ 内，取振幅高于分位 `amp_quantile`$=q$ 的交易日，其涨跌幅记 $\{r_i\}_{i=1}^{n}$
2. 风险调整动量（t 值）$\text{RAM}_t=\dfrac{\bar r\,\sqrt{n}}{\operatorname{std}(r)}$（要求 $n\ge3$、$\operatorname{std}>0$）
3. 三态 $s_t=\begin{cases}+1,& \text{RAM}_t>p\\-1,& \text{RAM}_t<-p\\ s_{t-1},&|\text{RAM}_t|\le p\end{cases}$

**建仓/平仓**：RAM>p 做多；RAM<−p 空仓；中间延续。窗口严格满窗（$t\ge L-1$ 才出值）。
**参数**：`lookback`(L), `amp_quantile`(q), `p`。
