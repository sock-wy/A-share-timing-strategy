# 02 信贷预期 · 策略年化收益率 8.4%

## 研报原文（P5-P6）

> 我们通过金融机构中长期贷款余额刻画信用扩张动能，衡量企业未来投资需求。
> 通过中长期贷款余额同比剔除季节效应，并通过长短均线差刻画信用扩张方向。
> - 当信用扩张方向为正，信号为 1；
> - 当信用扩张方向为负，信号为 -1。

## 数据频率
- 输入指标：`中长期贷款`（金融机构中长期贷款余额，亿元）—— **日度**（Wind 已将月度余额插值为日度）
- 回测：周度调仓、中证800

## 方法
1. 余额 **同比**（`value / value(去年同期)`）—— 同比天然剔除季节效应；
2. 同比序列做 **长短均线差**（短MA − 长MA）刻画信用扩张方向；
3. 方向 > 0 → 做多，< 0 → 空仓。

## 参数（`src/config.py -> PARAMS['信贷预期']`）
| 参数 | 含义 | 默认 |
|---|---|---|
| yoy_window | 同比窗口（交易日） | 252 |
| short_ma | 短均线（日） | 20 |
| long_ma | 长均线（日） | 60 |
