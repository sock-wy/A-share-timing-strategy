# 07 融资融券 · 策略年化收益率 7.66%

## 研报原文（P9）
> 我们将融资买入额/流通市值作为买盘资金强度，将融券卖出额/流通市值作为卖盘资金强度，
> 通过融资买盘强度中性融券卖盘强度的残差项，并以短期残差项均值作为融资融券买卖强度对比指标。
> - 融资融券买卖强度为正，信号为 1；
> - 融资融券买卖强度为负，信号为 -1。

## 数据 / 频率
- `融资融券`（margin_buy 融资买入额、short_sell 融券卖出额）—— **日度**
- `A股流通市值`（分母）—— **日度**
## 方法
1. 买盘强度 = 融资买入额 / 流通市值；卖盘强度 = 融券卖出额 / 流通市值；
2. 用买盘对卖盘做**中性化回归**取残差（`neutral_window` 滚动）；
3. 残差**短期均值**（`short_ma`）> 0 做多，< 0 空仓。
## 参数：neutral_window=60, short_ma=20（`config.PARAMS['融资融券']`，待校准）
