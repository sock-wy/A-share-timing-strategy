# 05 期货基差 · 策略年化收益率 9.09%

## 研报原文（P8）
> 我们以 IC 基差衡量期货市场的投资者预期，其向上偏离代表市场的乐观情绪与未来的上涨预期，
> 向下偏离代表市场的悲观情绪与未来的下跌预期。我们以 IC 基差的均线偏离度作为期货市场投资者情绪指标。
> - 当基差向上偏离超过阈值 p，信号为 1；
> - 当基差向下偏离超过阈值 -p，信号为 -1；
> - 当基差偏离度介于二者之间，则延续前信号。
