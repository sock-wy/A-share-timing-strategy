# 09 筹码结构 · 策略年化收益率 7.54%

## 研报原文（P11，源自《行业轮动3.0》）
> 我们假设每日存量全部持仓都会按照当日换手率均匀换仓，当日的成交均价作为该日的持仓成本，
> 通过每日滚动累积统计不同持仓价格下的存量筹码分布，通过指数现价相对持仓成本的收益率衡量市场赚钱效应，
> 将持仓成本高于现价的筹码与成交额比值作为阻力筹码，将持仓成本低于现价的筹码与成交额比值作为支撑筹码，
> 并通过 Zscore 衡量阻力筹码强度与支撑筹码强度。市场处于盈利状态下，支撑筹码强度占主导，
> 市场处于亏损状态下，阻力筹码强度占主导。
> - 市场盈利状态下，支撑筹码强度高于阈值 p，信号为 1；
> - 市场亏损状态下，阻力筹码强度高于阈值 p，信号为 -1；
> - 若未触发多空信号，则延续前信号。

## 数据 / 频率
- `中证800` OHLCV + `各宽基换手率`（中证800 换手率）—— **日度**
## 方法：换手率均匀换仓累积筹码分布 → 阻力/支撑筹码 → Zscore → 阈值 p 三态（含延续）。
## 参数：zscore_window=250, p=0.5（`config.PARAMS['筹码结构']`，待校准）
