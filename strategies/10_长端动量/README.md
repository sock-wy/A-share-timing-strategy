# 10 长端动量 · 策略年化收益率 8.72%

## 研报原文（P12，源自《长端动量2.0》）
> 在指数维度……我们通过振幅切割，指数维度高振幅交易日涨跌幅呈现更显著动量，
> 因此我们通过剔除低振幅交易日涨跌幅构建指数的长端动量指标。
> - 长端动量为正，信号为 1；
> - 长端动量为负，信号为 -1。

## 数据 / 频率
- `中证800` OHLCV（含 amplitude 振幅列）—— **日度**
## 方法
1. 回看窗口内按振幅分位切割，**剔除低振幅交易日**的涨跌幅；
2. 累加剩余（高振幅日）涨跌幅 = 指数长端动量指标；
3. 动量 > 0 做多，< 0 空仓。
## 参数：lookback=120, amp_quantile=0.5（`config.PARAMS['长端动量']`，待校准）
