# 01 宏观流动性 · 策略年化收益率 11.4%

## 研报原文（开源证券《权益择时的多策略框架》P5）

> 为刻画央行的流动性供给，我们将公开市场操作、常备借贷便利（SLF）、中期借贷便利（MLF）
> 和抵押补充贷款（PSL）4 个货币政策工具的净投放加总，作为宏观流动性的代理指标。
> 我们将净投放指标平滑后做 Zscore 处理，从而衡量央行的流动性供给强度。
> - 当流动性供给强度高于阈值 p 时，信号为 1；
> - 当流动性供给强度低于阈值 -p 时，信号为 -1；
> - 当流动性供给强度介于二者之间，则延续前信号。

## 数据频率
- 输入指标：`宏观流动性净投放`（OMO/SLF/MLF/PSL 净投放）—— **月度**
- 回测：周度调仓、中证800（月度信号 ffill 对齐到周度调仓日）

## 参数（`src/config.py -> PARAMS['宏观流动性']`）
| 参数 | 含义 | 默认 |
|---|---|---|
| smooth_window | 净投放平滑窗口（月） | 3 |
| zscore_window | 滚动 Zscore 窗口（月） | 36 |
| **p** | 三态阈值 | 0.5 |
