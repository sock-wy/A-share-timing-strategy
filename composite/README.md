# 合成策略（骨架，待实现）

10 个子策略信号合成为综合择时信号。两种方案：

## 7.1 等权合成（研报年化 16.79%）
> 我们将 10 个子策略等权聚合，构建综合信号（等权）。

实现：综合打分 = 10 个子策略 signal 的等权平均；打分 > 0 做多、≤ 0 空仓。

## 7.2 动态赋权（研报年化 22.15%，最终方案）
> 我们将基准指数日收益绝对值作为择时策略最优解……通过最小化过去 120 日组合信号收益
> 与最优解收益间的欧氏距离，动态调整子策略权重。
>
> min ‖ |Rₜ| − Σᵢ wᵢ·Sⁱₜ·Rₜ ‖²   s.t.  5% ≤ wᵢ ≤ 15%,  Σ wᵢ = 1

实现（用 `scipy.optimize.minimize`，SLSQP）：
- Sⁱₜ 为各子策略打分，Rₜ 为基准日收益；
- 每个调仓日用过去 120 日窗口解上述约束优化得到权重 wᵢ；
- 综合打分 = Σ wᵢ·Sⁱₜ，> 0 做多、≤ 0 空仓。
